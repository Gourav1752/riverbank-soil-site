Riverbank Soil Study — Dataset

File: riverbank_soil_before_after_flooding_dataset.csv
Rows: 100 (50 sampling locations x 2 periods)
Purpose: Demonstration dataset for a student project comparing soil indicators before and after flooding.

IMPORTANT:
All measurements in this file are SIMULATED for demonstration/testing. They are not real field observations and must not be reported as measured or published scientific data. Replace them with actual lab/field measurements or cite a suitable published dataset before drawing real-world conclusions.

Columns:
- sample_id: paired sampling location identifier (RB001–RB050); same ID represents the same illustrative location before and after flooding.
- period: Before flood / After flood.
- site_zone: illustrative distance zone from the riverbank.
- distance_to_river_m: approximate distance from river, in metres.
- sampling_depth_cm: illustrative sampling depth label (0, 10, or 20 cm).
- soil_texture: illustrative soil texture category.
- soil_pH: pH value.
- soil_moisture_pct: soil moisture, percent.
- nitrogen_mg_kg: nitrogen concentration, mg/kg.
- phosphorus_mg_kg: phosphorus concentration, mg/kg.
- potassium_mg_kg: potassium concentration, mg/kg.
- organic_carbon_pct: organic carbon, percent.
- electrical_conductivity_dS_m: electrical conductivity, dS/m.
- data_type: explicit provenance flag.

Suggested use:
1. Upload the CSV to the website repository.
2. Load it in the Data & Analysis page for charts/tables.
3. Label all charts and summaries as simulated sample data until replaced with verified observations.
